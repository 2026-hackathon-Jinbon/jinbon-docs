# 구현과 검증 결과

기준일: 2026-09-07

## 상태

가입, 로그인, DID, 영상 등록, VC, 앱 API, 웹 파일 검증, 확장 URL 검증은 코드 경로를 확인했습니다. 외부 연동, 실기기, 브라우저 실행은 아직 검증하지 않았습니다.

`./gradlew test --no-daemon`은 테스트 코드 컴파일 오류 6건으로 중단되었습니다. 등록 테스트와 검증 테스트가 현재 생성자와 삭제된 메서드를 참조합니다.

## 결선 전 확인

- DID 개인키 소유 증명
- VC Claim과 대상 영상 연결 검증
- 체인 receipt 지연과 DB 상태 불일치
- iOS 토큰 갱신 실패 조건
- iOS 목록 페이지 처리
- pHash 결과를 영상 전체 동일성으로 표현하지 않기
- YouTube 성공 결과 사전 실측

실행 전 videoId, txHash, vcId, 파일 해시, URL을 임의로 작성하지 않습니다. 공개 자료에는 토큰, CI, PIN, 개인키를 넣지 않습니다.
