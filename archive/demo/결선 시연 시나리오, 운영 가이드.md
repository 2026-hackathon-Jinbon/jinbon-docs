# 결선 시연 가이드

## 준비

iPhone과 화면 미러링, Chrome, 앱과 확장, 원본 A, 재인코딩 B, 미등록 C, 사전 확인한 YouTube URL을 준비합니다. 백엔드, PostgreSQL, Redis, OmniOne CX, 체인 RPC, Open DID, yt-dlp 상태를 확인합니다.

실기기에서 `localhost`는 iPhone 자신을 가리키므로 앱에는 접근 가능한 서버 주소를 넣어야 합니다. Netflix는 성공 플로우에서 사용하지 않습니다.

## 순서

1. 기존 로그인 상태로 앱 진입
2. 원본 A 등록, videoId와 txHash 확인
3. VC 발급과 ISSUED 확인
4. 웹에서 원본 A 검증
5. 확장에서 사전 등록 YouTube 확인
6. 미등록 C와 NOT_REGISTERED 의미 설명

가입과 외부 인증은 시간이 길면 보조 녹화로 분리합니다. 실패 시 반복 등록하지 말고 사전 등록 증거나 웹 파일 검증으로 전환합니다.

## 완료 기준

핵심 흐름 3회 연속 성공, 각 단계 시간 기록, 캐시 여부 기록, 공개 화면의 토큰과 개인정보 마스킹.
