# 서비스 기능 정의

기준일: 2026-09-07. 코드 확인과 실행 성공은 구분합니다.

## 목적

모바일 신분증으로 등록자의 신원을 확인하고, 영상의 SHA-256과 프레임 특징을 등록 기록으로 남깁니다. 이용자는 등록 기록과 비교한 결과를 확인합니다. 촬영 장면의 사실 여부나 저작권을 판정하는 서비스는 아닙니다.

## 채널별 범위

| 채널 | 확인된 기능 | 제한 |
|---|---|---|
| iOS | 가입, 로그인, DID 연결, 영상 등록, 내 영상, VC 발급과 조회, 파일 검증, 설정 | 외부 SDK와 실기기 확인 필요 |
| 웹 | 파일 선택과 드롭, 미리보기, 100MB 제한, 파일 검증, 결과 표시 | URL 입력, 회원가입, 영상 등록 UI 없음 |
| 확장 | 영상 페이지 버튼, URL 검증 패널, 백엔드 주소 설정 | YouTube와 Netflix를 인식하지만 Netflix는 백엔드 허용 목록에 없음 |

## 흐름

가입과 본인확인 → 영상 등록 → 체인 기록 → VC 발급 → 웹 또는 확장 검증.

영상 등록과 VC 발급은 별도 단계입니다. VC 발급이 실패해도 영상 등록 기록은 남을 수 있습니다.

## 결과

| verdict | 의미 |
|---|---|
| EXACT_MATCH | 등록 원본 파일의 SHA-256과 일치 |
| SAME_CONTENT | 비교된 프레임 특징이 거리 0 |
| SIMILAR_MATCH | pHash 거리가 임계값 미만 |
| REGISTERED_BUT_REVOKED | 등록 기록이 비활성화됨 |
| CERTIFICATE_INVALID | 연결된 VC 검증 실패 |
| NOT_REGISTERED | 일치하는 등록 기록을 찾지 못함 |
| VERIFICATION_UNAVAILABLE | 외부 장애나 무결성 확인 실패 |

pHash는 최대 10개 프레임을 비교합니다. SAME_CONTENT는 영상 전체, 음성, 시간 순서의 동일성을 증명하지 않습니다. NOT_REGISTERED는 위조 판정이 아닙니다.

## 현재 구현으로 주장하지 않는 것

별도 심사를 거친 공인만 등록한다는 정책, AI 딥페이크 판정, 웹 URL 입력, Netflix 정상 검증, 변조 전용 verdict, 기기 변경 후 VC 이전입니다.
