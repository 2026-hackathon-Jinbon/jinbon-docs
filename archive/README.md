## 현재 상태

Figma에는 iOS 시작 화면, 웹 검증 홈, 확장 핵심 화면이 반영되어 있습니다. 외부 연동과 실기기 검증은 아직 완료되지 않았습니다. 백엔드 전체 테스트는 테스트 코드 컴파일 오류로 중단되었습니다.
