서비스의 방향

발표자가 기준을 남기고,
시청자가 확인합니다.

가상의 기업 ‘누리테크’ 대표가 이용료 동결을 발표한다. 이후 같은 화면에 인상 안내 음성을 넣은 영상이 유통된다. 시청자는 공유하기 전 진본에서 등록 영상과 비교한다.

각자의 필요

발표자: 자신이 배포한 영상의 등록 기록을 남기고, 내용이 의심받을 때 비교할 기준을 제시한다.

시청자: 영상의 외형만 믿는 대신 등록 출처와 비교 결과를 확인한다.

첫 고객 가설: 기업 홍보팀·기관 공보팀. 공식 발표 업무에 등록을 포함하고 대중에게 검증 경로를 제공한다.

기존 주제 ‘모바일 신분증 기반 공인 영상 진본 증명 플랫폼’과 ‘진본 확인’ 팝업은 유지합니다. 공인 등록자는 모바일 신분증으로 본인확인을 완료한 등록자입니다. 기관의 공식 발행 권한 확인은 별도 과제입니다. 이번 시연은 본인확인된 개인의 등록 흐름을 보여주며, 기업명은 상황 설정입니다.

권장 구성: 같은 촬영본으로 두 가지 편집

발표 PPT에는 짧은 영상 3개를 넣고, 제출·백업용으로 3분 완결본도 만든다. 발표자가 필요성과 검증 원리를 직접 설명하고, 영상은 실제 동작을 증명한다.

제작 확인 · 원본 전체 열람·기관 권한 인증·인터넷 자동 모니터링은 현재 시연에서 구현 완료 기능으로 다루지 않는다.

설명할 검증 단계와 기술의 역할

시연에서는 “디지털 지문”으로 쉽게 설명하고, 발표 자료에서는 아래 구조로 기술의 역할을 연결한다.

단계실제 처리무엇을 알 수 있나
등록 ① 본인확인모바일 신분증 인증 → 계정과 Wallet DID 연결누가 등록했는지 식별할 기반. 소속·발행 권한 인증은 별도.
등록 ② 기록파일 SHA-256·pHash·영상/음성 지문 생성. 파일 해시와 pHash의 결합값 등을 온체인 기록에 연결.나중에 비교할 등록 기준과 기록.
등록 ③ VC 발급등록 증거 확인 → 발급 준비 → 사용자 동의·PIN → Wallet 수령 → 서버 연결 검증발급자가 확인한 영상 등록 사실.
검증 ① 정확 일치제출 파일 SHA-256으로 등록 파일 조회파일이 정확히 같으면 등록 증거 검증으로 이동.
검증 ② 유사 비교정확 일치가 없으면 pHash로 후보 검색, 1초 간격 영상·음성 지문 비교등록 후보와 샘플 구간이 얼마나 대응하는지.
검증 ③ 증거 대조블록체인 기록·서버 HMAC 재대조, VC 상태·등록자·영상 정보 결속 확인후보의 등록 증거가 유효한지.
검증 ④ 결과 해석콘텐츠 비교와 등록 증거 결과를 함께 반환정확 일치 / 유사 / 미등록 / 증거 문제 등을 구분.
제작자용 기술 메모
현재 유사도 승인 기준은 영상 커버리지 95% 이상·음성 90% 이상 등입니다. 탐지 정확도 95%라는 뜻이 아닙니다. 영상·음성의 최적 원본 대응 시간 오프셋이 같아야 승인합니다. 반복 장면 등으로 최적 오프셋이 다르면 보수적으로 확인을 보류합니다. 짧은 편집과 국소 변화가 통과할 수 있습니다.

촬영 전 확정할 것

01 · 시나리오 소재누리테크·김지훈은 가상 설정. 20~30초 분량의 발표 원본을 직접 촬영하고 원음·원본 파일을 보관한다.
02 · 네 가지 비교 파일등록 원본, 재인코딩본, 같은 화면의 음성 변경본, 무관한 미등록 파일을 준비한다. 조작 제작 방식도 기록한다.
03 · 실제 결과 기록각 파일의 최종 상태·등록 증거·영상/음성 비교 결과·소요 시간을 측정한다. 수치와 설명은 이 결과로 확정한다.
04 · 제품 화면과 해설 분리아직 화면에 없는 등록자·비교 구간은 해설 카드로 구분한다. 제안한 새 UI나 결과를 구현된 화면처럼 합성하지 않는다.
05 · 촬영 경로 안정화모바일 신분증, 체인 등록, Wallet VC 발급, 실제 URL 다운로드를 리허설한다. URL 장애에 대비해 파일 업로드 컷을 준비한다.
06 · 편집과 산출물3분 완결본 1개 + PPT 삽입용 50초·50초·30초 클립 3개. 실제 대기 생략 표시, 자막 포함, 로컬 파일로 재생 확인.
이번 시연의 성공 기준
보는 사람이 “왜 등록하는지”, “왜 비교하는지”, “어떤 단계로 확인하는지”, “결과로 어디까지 판단할 수 있는지”를 설명할 수 있어야 합니다. 음성 변경본에서 차이를 잡았다는 주장은 실제 결과로 뒷받침되어야 합니다.

추가 확인이 필요한 제품 과제: 기관 소속·발행 권한 확인, 등록 원본으로 이동하는 경로, 결과 화면의 근거 표시. 이 문서의 재작성은 제품 코드 변경을 포함하지 않습니다.
