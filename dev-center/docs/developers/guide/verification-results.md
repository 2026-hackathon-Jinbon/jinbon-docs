# 검증 결과 읽는 법

결과를 볼 때는 **일치 방식, 등록자·등록 시점, 상세 사유**를 함께 확인하세요. 웹·앱·챗봇의 문구는 달라도 API는 네 가지 표시 상태로 구분합니다.

## 진본: 일치 방식을 확인하세요

등록 증거가 유효하고, 다음 두 방식 중 하나를 통과한 상태입니다.

| 확인 방식 | 뜻 |
|---|---|
| **파일 정확 일치** | 제출한 파일 전체의 SHA-256이 등록 파일과 같음 |
| **유사도 기준 통과** | 파일은 다르지만 영상·음성 지문이 비교 기준을 충족함 |

유사도 통과는 샘플 기반 판정이므로 모든 프레임·음성이 바뀌지 않았다는 보장은 아닙니다.

‘원본의 2:10~2:40에 대응’은 등록 영상에서 비교된 위치입니다. 일치율은 **제출본의 비교 구간 중 지문이 대응한 비율**이며, 조작이 없을 확률이 아닙니다. [30초 클립 예시](/developers/guide/verification-methods#extracted-clips)에서 계산 방법을 볼 수 있습니다.

## 콘텐츠 유사: 후보는 찾았지만 승인 기준에 미달했습니다

대표 화면이 비슷한 등록 영상은 찾았지만, 영상·음성의 대응 비율이나 원본 대응 시점이 맞지 않거나 비교 정보가 부족한 경우입니다. 오디오 트랙이 없는 사본도 유사도 경로에서는 승인하지 못할 수 있습니다.

후보의 등록자나 유효한 보증서가 표시되어도 **제출 영상이 진본으로 승인된 것은 아닙니다.** 이 결과만으로 편집·딥페이크를 확정하지도 않습니다.

## 미인증: 상세 이유를 구분하세요

| 상세 이유 | 뜻 | 확인할 것 |
|---|---|---|
| **등록 기록 없음** | 현재 비교에서 후보를 찾지 못함 | 등록 여부, 제출 파일의 변환·편집 여부 |
| **등록 비활성화** | 찾은 등록의 사용이 중지됨 | 등록 상태. 기록 자체는 남아 있음 |
| **보증서 없음** | 등록은 되었지만 VC가 연결되지 않음 | 등록자가 앱에서 발급·연결을 마쳤는지 |
| **보증서 무효** | VC가 유효하지 않거나 해당 등록 정보와 맞지 않음 | 보증서 상태와 등록 건의 연결 |

미등록은 가짜라는 뜻이 아닙니다. 유사도 검색은 활성 등록만 대상으로 하므로, 비활성화된 영상의 재압축본은 ‘등록 기록 없음’으로 나올 수도 있습니다.

## 확인 불가: 현재 판정할 수 없습니다

`UNAVAILABLE`에 해당하며, 일부 화면에서는 ‘확인 중’으로 표시합니다. 블록체인·Open DID 연결 장애라면 재시도가, 블록체인 기록 불일치라면 운영자 확인이 필요합니다. 서버의 상세 사유를 함께 확인하세요. 이 상태가 자동 재검증 예약을 뜻하지는 않습니다.

URL 다운로드 실패 같은 요청 오류는 별개입니다. [다운로드 실패와 미등록의 차이](/developers/guide/verification-methods#download-failure)를 참고하세요.

## 등록자와 시점의 의미

- **등록자**는 비교 기준을 등록한 사람입니다. 표시명으로 기관 소속·직함·저작권을 인증하지 않습니다.
- **등록 시점**은 진본에 등록한 때입니다. 촬영·게시 시점과 다릅니다.
- **보증서**는 해당 영상의 등록 사실을 담습니다. 영상 내용의 사실성이나 AI 생성 여부를 보증하지 않습니다.

화면을 구현할 때 필요한 판정 코드와 응답 필드는 [검증 API](/developers/api/verify#display-status)를 참고하세요.
