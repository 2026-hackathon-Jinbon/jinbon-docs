# 검증 원리와 서비스 안내

진본은 영상의 비교 결과와 등록 기록, 등록 보증서를 함께 확인합니다. 먼저 [검증 결과의 의미](/verification-status)를 살펴보고, 세부 기준이 궁금할 때 이 안내를 참고하세요.

## 영상과 등록 기록을 함께 확인합니다

1. **영상과 음성을 비교합니다.** 파일이 정확히 같은지 먼저 확인합니다. 파일이 다르면 유사한 등록 영상을 찾아 대표 장면과 음성을 비교합니다.
2. **등록 기록을 대조합니다.** 블록체인에 남긴 영상의 대표 지문과 등록자 식별 정보 등을 대조하고, 등록이 유효한 상태인지 확인합니다.
3. **등록 보증서를 확인합니다.** 보증서의 유효성과 발급자·등록자 정보를 확인하고, 해당 영상의 등록 기록에 연결되는지 대조합니다.

## 음성 100% 일치, 어떻게 확인하나요? {#audio-verification}

음성 파일이 완전히 같다는 뜻이 아니라, **모든 비교 구간이 허용 오차 안에서 일치한다**는 뜻입니다.

1. **같은 형식으로 변환:** 음성을 모노·16kHz로 변환해 채널과 샘플레이트를 맞춥니다.
2. **1초 단위 지문 생성:** 각 구간의 소리 특징을 담은 음성 지문을 만듭니다.
3. **구간별 허용 오차 적용:** 지문에서 서로 다른 비트 수인 해밍 거리가 10 이하이면 해당 구간을 일치로 봅니다.
4. **모든 비교 구간 통과:** 비교 대상 구간이 모두 일치해야 음성 구간 일치율이 100%가 됩니다.

예를 들어 20구간을 비교했다면, 20구간 모두 일치하면 100%로 음성 기준을 통과합니다. 19구간만 일치하면 95%이므로 음성 기준을 통과하지 못합니다.

재압축된 영상도 구간별 허용 오차 안이면 통과할 수 있습니다. 다만 음질 저하 등으로 한 구간이라도 기준을 벗어나면 정상 영상도 진본으로 확인되지 않을 수 있습니다.

영상·음성 비교 경로에서는 영상 구간 일치율 95% 이상과 음성 구간 일치율 100%, 순서 보존과 동일한 원본 대응 시점이 필요합니다. 등록 기록과 보증서도 유효해야 진본으로 표시합니다. **이 수치는 판정 기준이며 조작 탐지 정확도를 뜻하지 않습니다.**

## 현재 데모와 앞으로의 계획 {#platform-plan}

진본은 현재 영상 등록·검증 흐름을 시연하는 데모입니다. 향후 플랫폼·콘텐츠 권리자와의 협력을 통해 영상 접근 경로와 출처 확인 근거를 강화할 계획입니다.

### 현재: 파일 업로드와 URL로 검증합니다

영상 파일을 직접 올리거나, 오픈소스 도구인 yt-dlp로 URL의 영상을 내려받아 등록 영상과 비교합니다. YouTube·Instagram 링크도 이 경로를 사용합니다. Instagram도 화면녹화 방식은 사용하지 않습니다.

URL 다운로드는 플랫폼의 공식 영상 제공 연동과는 별개이며, 로그인 요구나 접근 제한, 플랫폼 변경에 따라 이용이 어려울 수 있습니다. 이 경우 본인이 보유하고 검증에 사용할 권한이 있는 영상 파일을 직접 올려 확인해 주세요.

### 향후: 공식 API 연동과 영상 제공 계약

플랫폼 및 콘텐츠 권리자와의 협의를 바탕으로, 공식 API 연동과 검증 목적의 영상 제공 계약을 추진할 계획입니다.

영상 접근뿐 아니라 검증을 위한 분석과 지문 활용 범위도 함께 협의해, 승인된 범위에서 안정적으로 검증할 수 있는 구조를 목표로 합니다.

협력을 통해 제작자가 제공한 기준 영상과 SNS에 유통된 영상의 연결을 강화하고, 출처 확인과 변조 의심 신고 검토에 활용할 수 있는 근거를 제공하고자 합니다.

공식 연동과 영상 제공 계약은 향후 추진 계획이며, 현재 계약 체결이나 플랫폼의 공식 지원을 의미하지 않습니다. 실제 지원 범위와 일정은 협의·승인 결과에 따라 정해집니다.
